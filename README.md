# Nelson-Siegel Streamlit Research App

## Run inside JupyterLab

Open a terminal in JupyterLab and run:

```bash
pip install -r requirements.txt
streamlit run app.py
```

Upload your FRED files, for example:

- DGS3MO.xlsx
- DGS6MO.xlsx
- DGS1.xlsx
- DGS2.xlsx
- DGS10.xlsx
- DGS30.xlsx

The app estimates real Nelson-Siegel factors using grid search.
